# Course introduction

Welcome to the course **Govern agents with Agent Gateway, Agent Registry, and Policies**.

In this course, you'll gain the strategic expertise required to progress from managing agent sprawl and complex networking primitives to a centralized, zero-trust governance plane for your AI agent workforce by using the [Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform), [Agent Gateway](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/gateways/agent-gateway-overview), and [Agent Registry](https://docs.cloud.google.com/agent-registry/overview).

You'll explore modernization workflows where you move beyond individual agent deployments and manual security configurations to master unified policy enforcement for designing, deploying, and securing your agent workloads, focusing on both ingress (Client-to-Agent) and egress (Agent-to-Anywhere) security paths.

Additionally, you'll learn how to use Google Cloud tools including Agent Gateway, Model Armor, Cloud DLP, IAM/IAP, and Terraform to enforce content security, mitigate prompt injection, automate infrastructure, and secure tool access via unique mTLS personas.

The focus of this course is on eliminating security configuration drift and operational risk caused by unmanaged agent sprawl to deliver fully compliant, auditable, and secure zero-trust AI environments and achieve a drastic reduction in deployment time.1

This course is designed for Security Teams, Cloud Architects, and AI Platform Engineers planning to scale their AI capabilities with centralized governance. Participants should have a strong understanding of networking primitives (VPC, DNS) and foundational knowledge of Identity and Access Management (IAM).

In this course, you will learn to:

- Design end-to-end zero-trust governance using the Agent Gateway as a centralized policy enforcement point.
- Automate the deployment of the Agent Gateway and VPC network using Terraform.
- Implement unique Agent Identities (mTLS personas) and granular per-tool authorization with IAP and Common Expression Language (CEL) conditions.
- Establish content guardrails to prevent injection attacks and data leakage using Model Armor and Cloud DLP.
- Manage tool discovery with the Agent Registry and audit execution using distributed tracing in Cloud Trace.
- Detect and classify agent-specific security threats using Security Command Center.
