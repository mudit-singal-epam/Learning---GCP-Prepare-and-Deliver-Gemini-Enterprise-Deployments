# Module introduction

Content security guardrails

In this module, you will learn how to establish comprehensive content guardrails at the gateway level.

Standard firewalls inspect networking headers, but they cannot detect semantic threats like prompt injection, jailbreaks, or the accidental transmission of private customer data.

By configuring the CONTENT\_AUTHZ service extension and deploying [Model Armor](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/configure-model-armor) templates, you will implement automated content sanitization.

You'll also learn how to integrate advanced Cloud Data Loss Prevention (DLP) templates to dynamically inspect, mask, and redact sensitive corporate data at the network boundary, ensuring your AI ecosystem remains safe, private, and secure.

![Image](CSS Graphic Crop (5).png)

By the end of this module, you'll be able to:

* Deploy and bind the CONTENT\_AUTHZ service extension using [Model Armor](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/configure-model-armor).
* Configure [Model Armor](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/configure-model-armor) templates to detect and mitigate prompt injection and jailbreak attacks.

Integrate Cloud DLP de-identification templates with [Model Armor](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/configure-model-armor) to mask sensitive information like SSNs in model responses.
