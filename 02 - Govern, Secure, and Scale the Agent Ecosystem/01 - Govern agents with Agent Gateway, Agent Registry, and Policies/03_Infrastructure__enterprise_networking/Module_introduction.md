# Module introduction

Infrastructure and enterprise networking

In this module, you will learn how to master the core ingestion and transformation models of the Cortex Framework, and apply scalable compliance controls to newly ingested enterprise data. You will explore the Cortex Dual-Dataset Architecture, using Change Data Capture (CDC) pipelines to ingest continuous data streams from operational systems (SAP, Salesforce, and Oracle EBS) into BigQuery. You will also learn how to use Dataplex to apply governance policies and security controls inherited from the source systems.

By the end of this module, you will be able to:

- Implement the Cortex Dual-Dataset Architecture, establishing a clear boundary between the raw landing zone and the curated analytics layer.
- Configure Change Data Capture (CDC) pipelines to ingest continuous data streams from operational systems (SAP, Oracle EBS) into BigQuery.
- Map custom legacy enterprise schemas accurately to Cortex deployment patterns to avoid data integrity issues and preserve table relationships.
- Design a governance strategy that protects sensitive ERP data (like financial records and PII) within the Cortex Foundation.
- Apply Dataplex auto-tagging policies directly to the raw CDC layer.
- Validate that row-level and column-level security controls are successfully inherited from the source systems through to the consumption views.
