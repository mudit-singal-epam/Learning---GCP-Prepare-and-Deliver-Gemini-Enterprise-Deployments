# Module introduction

Centralized agent governance

In this module, you’ll learn the fundamentals of establishing a centralized governance plane for your AI agent workforce. As organizations scale their AI capabilities, managing agent sprawl and securing how agents communicate with internal systems becomes a complex infrastructure challenge.

By deploying the [Gemini Enterprise Agent Platform](https://docs.cloud.google.com/gemini-enterprise-agent-platform)'s [Agent Gateway](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/gateways/agent-gateway-overview), you will centralize security policies, manage access controls, and ensure zero-trust connectivity across all agent workloads.

This architecture eliminates the need for individual developers to manage complex networking primitives, allowing your security teams to maintain strict, consistent compliance boundaries while accelerating agent deployments from weeks to days.

By the end of this module, you'll be able to:

* Describe the architectural components of the [Agent Gateway](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/gateways/agent-gateway-overview).
* Differentiate between ingress (Client-to-Agent) and egress (Agent-to-Anywhere) security paths.
* Explain how the [Agent Gateway](https://docs.cloud.google.com/gemini-enterprise-agent-platform/govern/gateways/agent-gateway-overview) integrates with the [Agent Registry](https://docs.cloud.google.com/agent-registry/overview) and IAM policies to govern agent workloads.
