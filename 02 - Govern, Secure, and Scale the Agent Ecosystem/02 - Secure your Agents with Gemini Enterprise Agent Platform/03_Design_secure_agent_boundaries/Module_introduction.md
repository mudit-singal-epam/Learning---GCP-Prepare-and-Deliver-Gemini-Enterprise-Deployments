# Module introduction

---

Design secure agent boundaries

In this module, you'll design secure agent boundaries to protect complex workflows from security threats.

You explore how to decompose a monolithic architecture into narrow, role-based agents that minimize the potential impact of a security failure.

You'll analyze the worst-case scenario for each agent design to determine necessary controls and differentiate between controls that protect the underlying model and those that constrain the agent's autonomous capabilities.

By establishing these architectural boundaries, you'll learn how to build a foundation where individual failures remain contained rather than cascading into system-wide breaches.

By the end, you'll understand how these layers compose and where each one covers the gaps the others leave.

![Image](CSS Graphic Crop (5).png)

By the end of this module, you'll be able to:

* Design agent boundaries that adhere to least-privilege principles to limit the blast radius of potential failures.
* Evaluate proposed agent architectures using worst-case scenario analysis to identify necessary security controls.
* Differentiate between model-level controls that prevent manipulation and agent-level controls that constrain autonomous execution.
* Apply structural decomposition techniques to transform complex workflows into recoverable and reviewable system designs.
