# Course introduction

---

Welcome to the course **Secure your Agents with Gemini Enterprise Agent Platform**.

In this course, you’ll learn to establish centralized, zero-trust control and visibility over your AI workforce.

You’ll  build a secure and well-governed agent ecosystem using the Gemini Enterprise Agent Platform. You’ll deploy the Agent Gateway and Model Armor to manage agent sprawl and ensure secure interaction with enterprise data.

You’ll examine the configuration options to implement secure identity protocols, including delegated identity and multi-legged OAuth flows, and set up advanced monitoring and observability.

The deployed system will be ready for secure, authorized scaling within an enterprise-grade environment.

This course teaches you to secure AI agents the way they're actually attacked, layer by layer, with identity and access at the foundation.

Each module answers the next question in a single defense-in-depth arc:

1. Threat Landscape
2. Designing Secure Agent Boundaries
3. Agent Identity vs Service Accounts
4. Delegated identity and Multi-legged OAuth
5. Security perimeters and Network Isolation
6. Runtime Content Guardrails
7. This course teaches through two anchor use cases.

You'll study the Warranty Claim System, a three-agent enterprise reference architecture (Case Manager, Data Vault, Logistics Liaison) that automates customer warranty processing to demonstrate defense-in-depth security at scale.

Finally, you'll examine how to build the DevOps Assistant, an agent that reads a signed-in developer’s GitHub data on their behalf, to master the identity core hands-on in a dedicated identity lab.

In this course, you will learn to:

![Image](objective3.png)

**✓**Implement governance, monitoring, and observability for enterprise agents using the Agent Gateway and Model Armor.

**✓**Configure secure authentication and identity protocols, including delegated identity, service account impersonation, and multi-legged OAuth flows.

**✓**Scale the agent ecosystem by managing agent sprawl and ensuring secure, authorized access to enterprise data through centralized oversight.
