# Course summary

Congratulations! You have completed the course **Use a Third-Party Identity Provider with Workforce Identity Federation**.

You have moved from understanding the basic problem (Shadow IT) to architecting a complex, attribute-based access control system using modern Identity standards.

- Describe the architecture and token exchange flow of Workforce Identity Federation (WIF).
- Configure Identity Pools and Providers for both SAML 2.0 and OIDC.
- Implement attribute mapping and write CEL logic for access conditions.
- Bind IAM policies to federated identities.
- Utilize CLI/API access and investigate authentication logs.
