# Module Introduction

Welcome to this module, **The Logic of Access**.

This module delves into mapping external identity claims to Google Cloud attributes, constructing Common Expression Language (CEL) guardrails, and binding IAM policies to federated principal sets.

In this module, you'll learn to:

- Implement attribute mappings to extract user identity and group memberships from IdP tokens.
- Construct CEL attribute conditions to restrict access based on security requirements.
- Bind IAM policies to federated principal sets across projects and resources.
