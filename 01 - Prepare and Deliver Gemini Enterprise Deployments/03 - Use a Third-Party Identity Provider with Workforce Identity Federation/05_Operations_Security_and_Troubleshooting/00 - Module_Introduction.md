# Module Introduction

Welcome to this module, **Operations, Security, and Troubleshooting**.

This module covers day-to-day operations including federated console access, gcloud CLI and client library authentication using credential configuration files, and troubleshooting via Cloud Audit Logs.

In this module, you'll learn to:

- Configure and test federated Google Cloud Console login URLs.
- Authenticate the gcloud CLI and client libraries using STS credential configs.
- Enable STS audit logs and investigate authentication and authorization events in Cloud Logging.
