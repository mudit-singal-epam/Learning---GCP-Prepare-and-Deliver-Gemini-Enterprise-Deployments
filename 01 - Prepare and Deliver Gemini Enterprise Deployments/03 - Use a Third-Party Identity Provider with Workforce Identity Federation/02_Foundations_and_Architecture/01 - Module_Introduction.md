# Module Introduction

Welcome to this module, **Foundations and Architecture**.

This module explores the core concepts behind external identity federation, contrasting traditional account synchronization with token exchange, deconstructing the Security Token Service (STS) architecture, and comparing OpenID Connect (OIDC) with SAML 2.0.

In this module, you'll learn to:

- Deconstruct the Token Exchange flow into its component steps.
- Define the role of the Security Token Service (STS) in the Google Cloud IAM ecosystem.
- Distinguish between the Subject Token (Foreign Currency) and the Access Token (Local Currency).
- Compare OpenID Connect (OIDC) and SAML 2.0 protocols for workforce federation.
