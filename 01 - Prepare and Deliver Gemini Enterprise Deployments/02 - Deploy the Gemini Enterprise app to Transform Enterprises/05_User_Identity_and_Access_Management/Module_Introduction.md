# Module Introduction

Welcome to this module, **User Identity and Access Management module**.

The User Identity and Access Management module deals with the essential task of establishing a secure identity and access management foundation for Gemini Enterprise by selecting the appropriate identity provider and assigning necessary IAM roles is also addressed.

In this module, you'll learn to:

- Explain how to select an appropriate identity provider for Gemini Enterprise.
- State how to assign necessary IAM roles to establish a secure identity and access management foundation.
