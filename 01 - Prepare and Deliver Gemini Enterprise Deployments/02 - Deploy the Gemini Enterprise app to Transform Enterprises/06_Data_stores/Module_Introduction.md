# Module Introduction

Welcome to this module, **Data Stores**.

The Data Stores module explains the fundamental infrastructure of Data Stores and Connectors, which explains how they integrate Gemini Enterprise with data through various connection modes like ingestion and federation to enable grounded responses and agentic workflows.

In this module, you'll learn to:

- Describe the critical infrastructure of Data Stores and Connectors.
- Explain how Data Stores and Connectors integrate enterprise data through ingestion and federation to enable grounded responses and agentic workflows.
