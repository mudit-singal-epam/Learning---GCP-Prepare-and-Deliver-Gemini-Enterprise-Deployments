# Module Introduction

Welcome to this module, **Agents**.

The Agents module explores the shift from simple chatbots to Gemini Enterprise Agents, which are active digital workers capable of multi-step workflows, leveraging a creation spectrum that ranges from no-code Agent Designer to high-code Agent Engine, all under centralized governance.

In this module, you'll learn to:

- Differentiate between simple chatbots and Gemini Enterprise Agents, which are active digital workers capable of multi-step workflows.
- Evaluate the development spectrum that ranges from no-code Agent Designer to high-code Agent Engine, all under centralized governance.
